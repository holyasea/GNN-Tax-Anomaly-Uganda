WHY THE NUMBERS CHANGED (READ FIRST)
================================================================================

Three problems in the July-September pipeline were found and fixed. Any
number quoted from the previous version of this log is superseded.

1. SALES EXTRACT WAS TRUNCATED. The July extract stopped at 1,048,575 rows
   (the Excel row limit). The extract was rebuilt from the source in 19
   chunks (18 x 950,000 + 411,132 = 17,511,132 rows, no overlaps). The old
   "decline after 2018" and "17 of 28 zero-sales refund cases" findings were
   largely artefacts of the truncation and no longer stand.

2. CRITICAL GNN BUG FIXED (gnn_pipeline_actual.py). The rev-1 pipeline
   percentile-clipped node features over the FULL matrix (165,094 nodes,
   of which only 614 are taxpayers), which zeroed every node feature; the
   GNNs were effectively trained on nothing. Scores were degenerate (all
   614 taxpayer scores within 5.7e-6). Fixed: scaling fitted on taxpayer
   rows only; 3 structural features (log in/out-degree, PageRank) added
   for ALL nodes; reciprocal edges removed from the training graph;
   models scored by reconstruction error on HELD-OUT edges (15% mask);
   early stopping added; 3 seeds trained and averaged.

3. HYPOTHESIS TESTS REDESIGNED (rev 3, after supervisor feedback).
   - H1  previously mixed two claims (community structure AND power-law
         fit) in one decision rule. Community structure is now the only
         decision criterion; the degree distribution is descriptive.
   - H2  previously tested IF-flagged vs non-flagged taxpayers on the very
         features IF was trained on - circular by construction. The
         decision now rests on graph features IF never saw.
   - H4a now decided by top-k overlap (full-range Spearman ranks noise in
         the near-zero score mass); Spearman kept as secondary.
   - H4b permutation test added (the binomial assumed independent flag
         sets without checking).

HONEST READING (report this, including the caveats):
  - IF + GAT embeddings detect the structural patterns almost perfectly
    (0.98 / 0.97) while the tabular-only IF (D2) nearly misses them
    (0.20 / 0.05). This is the study's strongest pro-GNN evidence.
  - The rule baseline's 0.00 is a THRESHOLD ARTIFACT: tau set from the real
    large taxpayers' purchase scale is far above the injected nodes' scale.

FORMAL HYPOTHESIS TESTING (rev 3; script 04_hypothesis_tests.R, seed 7142)
================================================================================

H1: NETWORK TOPOLOGY - REJECT
  Graph (simplified, undirected): 165,094 nodes, 445,730 edges.
  Observed Louvain modularity: 0.4874.
  Null (1,000 configuration-model graphs, same degree sequence):
  mean = 0.3676, SD = 0.0003. z = 438.3; empirical p = 0.0010.
  Decision rule (rev 3): reject if p < 0.05. REJECTED - community structure
  is far above degree-matched chance.
  H1b (descriptive, not a decision): degree tail heavy (alpha = 2.21,
  xmin = 5); bootstrap KS rejects a pure power law (p = 0.0000), so describe
  it as heavy-tailed, not power-law.

H2: BASELINE DETECTION (rev 3, non-circular) - REJECT
  Rev-1 test (IF flags vs IF's own training features) was circular and is
  retained as a descriptive profile only. Decision now on 5 graph features
  IF never saw (Mann-Whitney U, BH-corrected):
    log_out_degree          : flagged LOWER  (4.51 vs 5.46), p_adj = 0.0029
    reciprocated_share      : flagged HIGHER (0.589 vs 0.356), p_adj = 0.0004
    max_counterparty_share  : flagged HIGHER (0.375 vs 0.253), p_adj = 0.0004
    log_in_degree, page_rank: not significant
  3 of 5 held-out features significant (min adj. p = 0.0004). REJECTED.
  Reading: IF-flagged taxpayers are concentrated, heavily reciprocal
  traders with fewer distinct connections - a coherent held-out signature,
  not a tautology.

H3: GRAPH-MODEL DETECTION - FAIL TO REJECT
  Flag groups differ structurally (smallest Kruskal-Wallis p < 0.0001), BUT
  GNN-unique flags (63) do NOT exceed the independence expectation (100.2).
  The supervisor's "wrong way" concern stands: being flagged by only one
  GNN is, if anything, less common than chance would predict.

H4a: SCORE INDEPENDENCE (rev 3) - REJECT (for one pair only)
  Primary: top-62 overlap vs permutation null (10,000 permutations):
    IF & RGCN  : 13 (expected 6.26), p = 0.0065
    IF & GAT   :  8 (expected 6.26), p = 0.2756
    RGCN & GAT : 26 (expected 6.26), p = 0.0001
  Secondary (full-range Spearman, ranks noise - do not lead with it):
    IF-RGCN -0.105 [-0.182, -0.026]; IF-GAT +0.038 [-0.041, +0.117];
    RGCN-GAT +0.233 [+0.157, +0.307].
  Reading: IF is independent of both GNNs; the two GNNs share real signal
  with each other at the top of their rankings.

H4b: CONSENSUS PRECISION (rev 3) - REJECT
  Observed consensus (>= 2 flags): 35. Expected under independence: 17.52.
  Binomial p = 0.0001. Permutation test (10,000 permutations of all three
  score vectors): permuted mean 17.52 (SD 3.38), p < 0.0001. Total pairwise
  overlaps 47 vs 18.78 expected (Poisson p < 0.0001).
  Reading: model agreement at the top of the rankings is non-random, and
  the permutation test confirms it does not depend on the binomial's
  independence assumption.

SUMMARY TABLE:
  H1   reject          - community structure above degree-matched chance
  H2   reject          - IF flags track held-out graph anomalies (non-circular)
  H3   fail to reject  - GNN-unique flags do not exceed chance
  H4a  reject (partial)- RGCN & GAT share top-ranked signal; IF does not
  H4b  reject          - consensus exceeds independence (permutation-confirmed)

BLINDED AUDITOR REVIEW SET (45 CASES)
================================================================================

WHY 45 CASES: the supervisor asked for 'a small blind review of flagged versus
random cases by URA auditors'. A review of flagged cases only cannot show
anything - reviewers asked to confirm suspects will confirm them. Mixing in
non-flagged controls turns the exercise into a discrimination test: if the
models' flags carry real information, auditors should rate consensus cases as
more suspicious than the controls; if the ratings come out the same, the flags
add nothing over chance.

COMPOSITION:
  - 35 CONSENSUS cases: every taxpayer flagged by 2 or more of the three
    models (top 10% per model). This is the pipeline's full actionable output,
    so the review mirrors how the tool would actually be used.
  - 10 CONTROL cases: non-flagged taxpayers matched on what an auditor sees
    first - total sales and total purchases. Each control sits within 1.5 SD
    of the consensus group's medians in (log sales, log purchases) space and
    the 10 closest were taken (seed 9413). Without size matching, reviewers
    could 'detect' flagged firms simply because they are bigger.
  - SHUFFLED: the review file holds case_num, node_id and the four visible
    metrics in random order; the consensus/control labels stay in the two
    case-card files, so the reviewer cannot tell which is which.
  - TASK: auditors rate each case 1-10 on suspicion; the analysis then
    compares consensus vs control ratings.

CAVEATS (state these in the write-up):
  - Controls are matched on financial size only, not on graph position -
    deliberate, because the question is whether the GNN flags add signal
    beyond what a size-similar firm looks like on paper.
  - 10 controls give only a coarse comparison; this fits the
    feasibility-study framing.
